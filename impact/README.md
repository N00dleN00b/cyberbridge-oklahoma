# Impact Tracking (optional)

Two simple, optional tools for anyone running CyberBridge sessions:

- **`workshop-tracker.csv`**: one row per session (date, place, audience, headcount, notes). Open it in Excel or Google Sheets.
- **`pre-post-survey.md`**: an anonymous 2-minute survey to see whether students learned to spot scams and whether they see study abroad as possible for them. Use it if the host allows it; skip it if time is short.

Never collect student names or contact details.
