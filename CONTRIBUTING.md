# Contributing

Teachers, librarians, students and security professionals are all welcome to improve these materials.

## Ways to help

- **Ran a lesson?** Open an issue using the "Lesson feedback" template: what worked, what confused students, how long it really took.
- **Found an error or outdated fact?** Open an issue or a pull request. Cybersecurity changes fast; corrections are very welcome.
- **Adapted a lesson** (Spanish translation, younger grades, tribal community context, etc.)? Submit it as a new file next to the original, e.g. `handout-es.md`.
- **New Phishing Spotter scenarios:** add them to the `SCENARIOS` list in `activities/phishing-spotter/index.html`. Keep them realistic for Oklahoma students (school, sports, jobs, gaming, family).

## Guidelines

- Write for a beginner. If a term needs a definition, define it.
- Keep it free: no paid tools or accounts required for students.
- Protect students: never include real student names, photos without permission, or real phishing links.
- Teach defense only. Activities show how to recognize and avoid attacks, not how to carry them out.
