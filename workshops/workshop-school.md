# Run of Show: School Classroom Workshop

**Length:** 50–60 minutes (one class period) · **Audience:** grades 7–12 · **Devices:** optional

This combines the highest-impact parts of all modules into one visit. For a multi-visit series, teach each module fully instead.

| Time | Segment | Source |
|---|---|---|
| 0:00 | Pre-survey (2 min, anonymous) | `impact/pre-post-survey.md` |
| 0:02 | Welcome + "Is it AI?" stand-up game | Module 1, step 1 |
| 0:07 | How machines learn + "you are training data" | Module 1, step 2 |
| 0:13 | Phishing red flags (SLAM) | Module 2, step 2 |
| 0:20 | **Phishing Spotter** (game or cards) | `activities/phishing-spotter/` |
| 0:30 | Passphrases + 2-step verification | Module 2, step 5 |
| 0:36 | Creator's story + a view from China | Module 3 step 1 + Global Perspectives step 1 |
| 0:43 | **Study abroad is for you: Gilman segment** | `gilman-segment.md` |
| 0:48 | Career quick-hits + free next steps | Module 3, step 4 |
| 0:52 | Be the Protector pledge / Teach-Back card | Module 2 handout |
| 0:55 | Post-survey + thank you | `impact/pre-post-survey.md` |

## What to bring
Printed handouts (Module 2 + Module 3), pre/post surveys, Phishing Spotter cards (backup), QR code slide, pens.

## Teacher talking points (when booking)
- Free, no prep for the teacher, fits one class period
- Supports computer science, career readiness and digital citizenship goals
- Students leave with practical safety skills to share at home, plus scholarship and career pathways
