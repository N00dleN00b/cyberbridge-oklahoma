# Module 2 Activities

## Part A: Control Sort

**Time:** 8 minutes · **Groups of 3–4**

Print the grid on a large sheet and the controls on small cards. Groups place each card in the right **row** (when it acts) and **column** (what it is). Some cards fit more than one place; let groups argue it out.

|  | Technical | Administrative | Physical |
|---|---|---|---|
| **Preventive** | | | |
| **Detective** | | | |
| **Corrective** | | | |

### Control cards (with suggested answer)
| Card | Row | Column |
|---|---|---|
| Multi-factor authentication | Preventive | Technical |
| Security awareness training for staff | Preventive | Administrative |
| Locked server room | Preventive | Physical |
| Automatic software updates | Preventive | Technical |
| Rule: "Never share your password" | Preventive | Administrative |
| "New sign-in" alert on your phone | Detective | Technical |
| Security cameras | Detective | Physical |
| Reviewing who accessed student records | Detective | Administrative |
| Offline backups of files | Corrective | Technical |
| Incident response plan ("who do we call?") | Corrective | Administrative |
| Fire extinguisher / backup generator | Corrective | Physical |
| Antivirus that blocks and removes malware | Preventive / Corrective | Technical |

### Connect to Oklahoma threats
For each scenario, groups pick **two controls** that would have helped:
1. A school district staff member clicks a fake "payroll update" email and enters their password.
   *(e.g. training, MFA, sign-in alerts)*
2. Ransomware locks a hospital's patient records.
   *(e.g. updates, backups, incident response plan)*
3. A grandparent gets a call from a cloned voice asking for gift cards.
   *(e.g. family code word = administrative control; calling back on a known number)*

## Part B: Phishing Spotter (Card Version)

**Time:** 10 minutes · **Pairs or groups of 3**

Use this if devices aren't available. The same scenarios are in the online game at `activities/phishing-spotter/`.

Print each scenario on its own card. Pairs decide **SAFE** or **SCAM**, and must name at least one clue. Then reveal and discuss.

All companies, numbers and links below are fictional.

---

**Card 1**
Text from (405) 555-0182: *"OKTurnpike: You have an unpaid toll of $4.15. Pay within 24 hours to avoid a $50 late fee: okturnpike-pay.co/settle"*
**Answer: SCAM.** Urgency, a small amount to seem harmless, and a look-alike website. Check tolls only through the official site or app you already know.

**Card 2**
In-game DM: *"Yo I'm giving away free skins to the first 20 ppl!! Just log in here so I can send them: free-skins-drop.gg"*
**Answer: SCAM.** Too good to be true, and it asks you to log in through a link. This is how gaming accounts get stolen.

**Card 3**
Email from your school's usual address, sent to the whole class: *"Reminder: picture day is Thursday. Order forms are in the front office."*
**Answer: SAFE.** No link, no request for info or money, expected sender, normal tone.

**Card 4**
Text: *"Hey it's Jordan, I accidentally sent my verification code to your number, can you send it back to me?"*
**Answer: SCAM.** Never share a login code. That code is the key to *your* account, which they're trying to take over.

**Card 5**
Email: *"Congratulations! You've been selected for a remote job: $45/hour, no experience needed. Reply with your full name, date of birth and bank info for direct deposit."*
**Answer: SCAM.** Too good to be true, and asks for sensitive info before any real interview.

**Card 6**
A notification inside your bank's official app (which you opened yourself): *"New sign-in on a Windows device. Was this you?"*
**Answer: SAFE (probably).** It's inside the official app you opened yourself. If it wasn't you, change your password from inside the app.

**Card 7**
Voicemail: *"Grandma, it's me, I'm in trouble and need bail money. Please don't tell Mom. Can you buy gift cards and read me the numbers?"*
**Answer: SCAM.** Panic, secrecy and gift cards are classic signs. Voice can be faked with AI. Hang up and call the family member directly; use the family code word.

**Card 8**
Email from "Micros0ft Support" (with a zero): *"Your account will be deleted today. Verify now."* Link text says microsoft.com but hovering shows a different address.
**Answer: SCAM.** Misspelled sender, urgency, and the link's real address doesn't match.

## Debrief questions
- Which card was hardest? Why did it feel real?
- What red flag showed up most often? (Usually: urgency)
- What's the safe move when you're not sure? (*Go to the app or website directly, or ask a trusted adult.*)
