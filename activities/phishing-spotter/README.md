# Phishing Spotter

A free, single-file browser game: read 12 messages (texts, emails, DMs, voicemails, pop-ups) and decide **Safe** or **Scam**. Instant feedback explains the clues.

- Works offline: just open `index.html`
- Works on Chromebooks, laptops and phones
- No accounts, no tracking, no data collected
- Includes scenarios for each local threat in the project: **school-district phishing**, **health-record / hospital scams**, and **scams targeting families**
- Keyboard: `S` = Safe, `X` = Scam

## Use in a workshop
Put the GitHub Pages link (or a QR code of it) on a slide. Students play in pairs for ~10 minutes, then debrief: *Which one fooled you? Why did it feel real?*

No devices? Use the printed card version in `curriculum/module-2-understanding-security-controls/activity.md`.

## Add scenarios
Edit the `SCENARIOS` list near the top of the `<script>`. Keep every name, number and link fictional (use `.example` domains and `555` numbers).
